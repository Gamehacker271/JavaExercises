# Ejercicios de Programación en Java


### Descripción
Este repositorio contiene la solución a 5 ejercicios prácticos de Estructura de Datos. El proyecto demuestra el uso de operadores matemáticos, bucles (`while`, `for`,).

### Estructura del Proyecto
El código fuente está dividido en paquetes individuales para asegurar su aislamiento y evitar conflictos de compilación:
* **Ejercicio1:** Determina si un número ingresado por el usuario es divisible entre 2.
* **Ejercicio2:** Calcula el precio final de un producto agregando un IVA del 21%.
* **Ejercicio3:** Imprime los números del 1 al 100 usando un ciclo `while`.
* **Ejercicio4:** Imprime los números del 1 al 100 usando un ciclo `for`.
* **Ejercicio5:** Identifica los números del 1 al 100 que son divisibles entre 2 y 3.

### 🚀 Ejecutables
Para facilitar la revisión, los archivos ejecutables (`.jar`) de cada ejercicio están compilados y listos para descargar en la sección de **[Releases](../../releases)** de este repositorio.

### 🛠️ Cómo ejecutar
1. Asegúrese de tener Java (JRE/JDK) instalado en su sistema.
2. Descargue el archivo `.jar` que desea probar desde la sección de Releases.
3. Abra una terminal en la ruta de descarga y ejecute el siguiente comando:
   ```bash
   java -jar NombreDelArchivo.jar
